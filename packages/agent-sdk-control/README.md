# `@ddlqhd/agent-sdk-control`

Internal **control-plane kernel** for first-party hosts (`agent-sdk` CLI / Web, `agent-sdk-acp`).

This package is **not** a Codex-style public app-server protocol. Third-party apps should keep using [`Agent`](https://github.com/ddlqhd/agent-sdk/blob/main/docs/sdk-overview.md). See [`docs/adr/0001-control-kernel.md`](../../docs/adr/0001-control-kernel.md).
